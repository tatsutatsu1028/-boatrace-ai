## まとめ（先に結論）

- **全場共通の取得元がある。** 公式映像サービス BOATCAST（運営: BOATRACE振興会 = boatrace.jp と同じ）が、各場のオリジナル展示を **1レース1ファイルのタブ区切りテキスト** で置いている。
  `https://race.boatcast.jp/txt/{場コード}/bc_oriten_{YYYYMMDD}_{場コード}_{レース番号2桁}.txt`
- **公開しているのは 23場。江戸川だけ公開なし**（BOATCAST にも場サイトにも無い）。
- 項目は場によって違う: **一周・まわり足・直線が19場**、**一周・まわり足だけが3場**（住之江・尼崎・徳山）、**桐生だけ「半周ラップ」・まわり足・直線**。
- 載せ方はどこも **文字（テキスト／HTMLの表）**。画像だけ・PDFだけの場は無かった。→ **OCR（`original_exhibition_ocr.py`）は不要**。
- 掲載は **締切の約10〜17分前**（59レースの中央値 13分前、最も遅くて6分前）。場サイトも同じ時刻に更新される。
- **過去分は BOATCAST で約2年分**（2024-09-03 は取得できた、2023-10-24 は取得できない）。各場サイトは当日分しか見られない。
- 規約: BOATCAST のサイトポリシーに **自動取得を禁止する条文は無い**。禁止されているのは「大量のアクセスなど運営に支障を与える行為」と、私的使用を超える **コンテンツ（著作物）** の無断利用。計測値は事実のデータなので、前回の調査（`REPORT.md` 5-4）と同じ基準なら問題ない側。ただし後述の注意あり。

**機械で安定して集められる場: 23場（江戸川以外）＝ 全レースの約 96.3%**（2026-06-01〜10-22 の 22,340レースで計算。江戸川は 3.70%）。

## 2. 主な取得元: BOATCAST

### 2-1. ファイルの中身

```
data=
1	3                    ← 2つ目の数字が項目数（3 または 2）
一　周	まわり足	直　線   ← 見出し（場によって違う）
1	（選手名）	37.34	5.78	6.21
…（6艇分）
```

- 計測できなかった艇は空欄（鳴門の FAQ では「-」表示と説明）。
- まだ掲載前のレースは **HTTP 403** が返る（ファイルが無い状態）。

### 2-2. 欠けの確認

直近の開催日（10/21〜10/23、41場・日、492レース）を全レース取得:

- 江戸川（24レース）を除く **468レース すべてにファイルがあった**。
- うち **459レースは6艇とも値あり**、**9レースは1艇だけ空欄**（計測不能。再展示・転覆など）。

### 2-3. 掲載時刻（締切の何分前か）

10/23 夜（住之江・大村・若松）と 10/24 午前〜昼（14場）に、締切40分前から約60秒ごとにファイルを見て、初めて値が入った時刻を記録した（59レース。誤差は±1分程度）。

| | 締切の何分前に載ったか |
|---|---|
| 中央値 | **13.4分前** |
| 9割のレース | 9.5〜17.3分前 |
| 最も早い／遅い | 25.2分前（浜名湖）／ 6.2分前（若松） |

場ごとの中央値（観測数）: 平和島 13.4(3)・多摩川 10.4(3)・浜名湖 17.3(3)・津 13.4(3)・三国 11.5(7)・びわこ 12.0(4)・住之江 16.1(2)・尼崎 14.4(3)・鳴門 10.6(7)・宮島 14.9(4)・若松 9.6(8)・芦屋 13.5(7)・福岡 13.9(2)・大村 13.1(3)

### 2-5. 規約

BOATCAST サイトポリシー（https://boatcast.jp/static/sitepolicy/index.html ）の要旨:

- 「著作権者の許諾なく、私的使用など法律によって認められる範囲を超えて、無断で使用（複製、改ざん、頒布などを含む）することはできません」（対象は文書・画像・ソフトウェア等の **コンテンツ**）
- 禁止事項に「不正アクセス、**大量の情報送受信及び大量のアクセス** など、本サイトの運営に支障を与える行為」
- 自動取得・クローラ・スクレイピングを名指しで禁止する条文は **無い**（boatrace.jp のサイトポリシーとほぼ同文）
- robots.txt は取得できず（403）

注意点:
- `bc_oriten_*.txt` は BOATCAST 自身の画面用のデータで、**公開APIとして案内されているものではない**。URLや形式が予告なく変わる可能性がある（ポリシーにも「URLを予告なく変更もしくは削除することがあります」とある）。
- 計測値（タイム）は事実のデータで、前回の調査と同じ考え方なら利用して問題ない側。ただし、取得した値を画面にそのまま一覧表示・再配布する使い方は「複製・頒布」に近づくので、使うなら予想の計算に使うだけにとどめるのが安全。
- 取得頻度は既存の `polite_http.py`（毎秒0.3リクエスト以下）の範囲で十分まかなえる（1レース1ファイルなので、1日あたり最大約200リクエスト）。

## 3. 機械で安定して集められる場

| 区分 | 場 | 場数 | 全レースに占める割合 |
|---|---|---|---|
| BOATCAST から取れる | 江戸川以外すべて | **23場** | **96.3%** |
| 公開なし | 江戸川 | 1場 | 3.7% |

- 割合は `history_full.csv` の 2026-06-01〜10-22（144日、22,340レース）から計算。場ごとの割合は 3.3%（丸亀）〜5.3%（尼崎）で、極端な偏りは無い。
- 「一周・まわり足・直線」の3項目そろいで比べたい場合は、直線の無い住之江・尼崎・徳山（計13.9%）と、一周の代わりに半周ラップの桐生（4.2%）が外れるので **19場・約78%** になる。場ごとに項目の意味（計測区間）も違うので、使うなら場内での順位など、場ごとに比べる形にするのがよい（`prediction.py` は既に順位ベース）。

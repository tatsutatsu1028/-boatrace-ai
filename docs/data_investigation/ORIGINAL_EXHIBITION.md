# オリジナル展示（一周・まわり足・直線）の各場の公開状況（調査: 2026-11-09〜10）

万舟チャンスのレースのオリジナル展示を自動で記録する（`original_exhibition_fetcher.py`）ための調査。
文字（HTML の表）で取れる場だけを対象にし、画像のみ・未確認の場は対象外にしている。

## 調べ方

- 各場の公式サイトのトップページと robots.txt を1回ずつ取得（間隔 2〜3 秒）
- オリジナル展示のページは、トップページの「直前情報」タブを開いたときにページ自身の JavaScript が組み立てる URL だけを使った
  （推測した URL は使わない方針。途中でいくつか試したものは 404/403 で、使っていない）
- 中身の確認は 2026-11-09 の開催場（12R）。非開催の場は、タブの有無まで
- 利用規約・サイトポリシーはトップページからリンクされているものを確認

## 利用規約・robots.txt

- robots.txt: 確認できた場はどこも、予想・直前情報のページ（`/modules/yosou/` など）を禁止していない
  （XOOPS 系の場は管理画面などだけを禁止。`Disallow:` 空の場あり。404 の場は robots.txt なし）
- 規約: 自動取得・クローラーを名指しで禁止している場は見つからなかった。共通するのは著作権の条項
  （「私的使用など法律で認められる範囲を超える複製・頒布・転載は許諾が必要」。公式 boatrace.jp・宮島・浜名湖など）
- → 個人の分析用に記録するだけなら範囲内。**取った値を記事・投稿（note・スレッズ・Discord）にそのまま載せない**こと
- 負荷: 1レース1回（未公開・失敗のときだけ1回取り直す）、`polite_http` で開始間隔 3.4 秒以上

## 展示後何分で出るか

今回は開催時間外の調査で、計測できていない。ページの注記では「一周・まわり足・直線」は周回展示の計測値
（下関は「周回展示2周目」）なので、展示タイムと同じころに出ると見込んで、展示後予想（展示タイムが6艇そろった後、締切20〜5分前）
のタイミングで1回取り、未公開なら次の起動（4分以上あと）に1回だけ取り直す。
実際に何回目で取れたかは `original_exhibition_log`（status・attempts・last_tried_at）に残るので、1〜2週間後に場ごとに集計して見直す。

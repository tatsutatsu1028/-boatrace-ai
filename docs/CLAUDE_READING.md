# ＋Claude予想（Claudeの読み と モデル＋Claudeの買い目）

管理者（owner）だけの機能。スタッフの画面にはタブが出ず、スタッフの操作では Claude の API を一切呼ばない。

## 動き

1. 予想タブで「🤖 AI最終予想」を押すと（管理者のときだけ）、モデルの予想・買い目を作ったあとに
   レースの入力データ（級別・勝率・当地勝率・モーター/ボート2連率・平均ST・F/L・体重・展示タイム・展示ST・
   チルト・部品交換・今節成績・コース別成績・風・波・気温・水温）とモデルの1〜3着確率を Claude に渡し、
   各艇の1着確率と短い理由、レース全体の見立てを受け取る（`claude_reader.read_race`）。
   データに無いことを書かないこと、1号艇を低く見すぎないことを指示している（`SYSTEM_PROMPT`）。
2. 1着確率をモデルと Claude の平均に置き換え、2着・3着はモデルの条件付き確率のまま3連単を組み立て、
   モデルの買い目と同じ手順（点数・保険・補充・資金配分）で「モデル＋Claudeの買い目」を作る（`claude_tab.build_tickets`）。
3. 「🤖＋Claude予想」タブに、モデル・Claude・平均の1着確率と理由、両方の買い目を並べて表示する。
   このセッションで予想したレースを選んで開ける。「記事に使う買い目」でモデル＋Claude を選ぶと、
   予想タブの note・スレッズの買い目がそちらに替わる（このセッションの間）。
4. Claude の確率・理由・見立て・モデル＋Claude の買い目は `prediction_snapshots.payload_json` の `"claude"` に保存する。
   結果確定後（自動の結果取り込み・オッズ追跡・手動保存）、`prediction_results` の次の列に当たり外れが入る:
   `claude_p1_lane`・`claude_first_hit`・`mix_p1_lane`・`mix_first_hit`・`mix_candidate_count`・
   `mix_candidate_hit`・`mix_hit_any_ticket`・`mix_total_stake`・`mix_payout`（手動保存では払戻は空）。
   モデルの買い目の当たり外れは今までどおり `candidate_hit`・`hit_any_ticket`・`payout`。

今のモデル（current）でも新しいモデル（ml）でも、予想の形（`p_first`・`p_second_given_<a>`・
`p_third_given_<a>_<b>`）は同じなので、そのまま動く。

## 設定（Streamlit の Secrets）

| キー | 内容 | 既定 |
|---|---|---|
| `ANTHROPIC_API_KEY` | API キー | （必須） |
| `CLAUDE_READ_MODEL` | 読みに使うモデル | `claude-opus-5-5` |

Opus 系・Sonnet 5.5 では、安全上の理由で回答が控えられたときに別のモデルで自動でやり直す設定
（server-side fallback）を付けている。

## 費用

- 1回あたり: 入力 約2,500トークン・出力 約1,500〜3,000トークン（考える分を含む）で、Opus 5.5 だと
  約0.04〜0.07ドル（6〜10円程度）。実際の値はタブの下に毎回表示する。
- 同じレース・同じ入力・同じモデルなら呼び直さない（アプリの中のキャッシュと、保存済み予想の `"claude"` で判定）。
  展示データが出て入力が変わったときは、もう一度押すと新しく読む。
- 失敗・60秒を超える遅延のときは、タブの Claude の欄が「取得できませんでした」になるだけで、モデルの予想と
  買い目・保存は通常どおり。

## 予想と結果の照合（管理者だけ）

- 予想タブ: 「AI最終予想」の後、買い目の点数の下に「モデルの買い目」と「モデル＋Claudeの買い目」を左右に並べる
  （スマホでは上下）。片方にしか無い買い目に★。各艇の1着確率（モデル・Claude・平均）とClaudeのまとめも添える。
  Claude が取れなかったときは何も足さない（モデルの買い目だけ）。詳しい理由は「＋Claude予想」タブ。
- 「＋Claude予想」タブの先頭「📋 今日の照合」: その日に予想を保存したレースごとに、実際の3連単・モデルの買い目の
  的中（○×）と払戻・モデル＋Claudeの買い目の的中と払戻。結果が無いレースは「結果待ち」。最後にその日の
  的中数・払戻・回収率の合計（モデル／モデル＋Claude）。Supabase からはその日の行だけ、
  予想は6列・結果は8列だけを取る（予想の中身 payload_json は取らない）。1分ごとに読み直す（`daily_review.py`）。
- 結果は自動で保存されるので、予想タブの手動の結果保存は管理者の画面から外した（スタッフの画面には残す）。
  自動で入らなかったときの予備は、検証タブの一番下「🔧 結果の手動保存」（日付とレースを選んで、公式結果を取得して保存、
  または着順と受取額を入れて保存）。
